changing the permissions :-
we have three type of permissions they are read , write and execution 
we give this permissions to the root user , group and others
the permissions are given in two ways one is numerical and alphabet  
NUMERICAL:-
r_ _ = 2^2 =4
_ w _= 2^1 =2 
_ _ X= 2^0 =1
rwx=4+2+1=7
r_x=4+1=5
in the same way different permissions are given
chmod 777 filename--->the command used to give the permissions
                   first 7 is for the user purpose
                    second 7 is for the group  purpose
                    third 7 is for the other purpose 
ex: chmod 741 filename---> user has all permissions wrx
                  group has only write permission w_ _
                  other has only execution permission_ _ x
ALPHABET:
= ..>to set permissions
+ ..>to add permissions
- ..>to remove permissions
a ..>everyone / all
u ...>user
g ..>group
o ..>other
ex: chmod a=rwx filename--> giving all permissions
    chmod g=wx filename ---> giving w_ x permission for group

user management:-
Create a New User:  sudo adduser <username>
set Password for the User: sudo passwd <username>
Add User to a Group: sudo usermod -aG <groupname> <username>
Change User Information: sudo chfn <username>
Change User's Primary Group:sudo usermod -g <groupname> <username>
Add User to Additional Groups:sudo usermod -aG <groupname1>,<groupname2> <username>
Change Username:sudo usermod -l <newusername> <oldusername>
Remove User:sudo userdel <username>
List All Users:cat /etc/passwd
View Groups for a User:groups <username>
View Specific User Information:id <username>
Create a New Group:sudo groupadd <groupname>
Delete a Group:sudo groupdel <groupname>
Grant Sudo Privileges to a User:sudo usermod -aG sudo <username>(give all the permissions that root user has but we need to use the sudo before every command and it add us wheel group)
Revoke Sudo Privileges from a User:sudo gpasswd -d <username> sudo
